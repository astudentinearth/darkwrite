# Export your workspace
You can take out all your notes as HTML files and use them in any other app that supports HTML content.  
> Currently only text contents can be exported. We will include more content in exports soon, starting with images.  

## How to export
To export your workspace, go to the **Settings** page from the sidebar. In the **Workspace** section, choose **Export all notes**. In a short while, you will be prompted to save a ZIP archive.

> This workspace export cannot be bulk-imported back to Darkwrite as a backup/restore mechanism. For this, use the built-in **[Backup and Restore](/docs/backup)** feature.
