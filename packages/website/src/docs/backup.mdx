# Backup and restore

Create a backup of your application data in a matter of seconds.


## Create backup

To backup your data, go to the **Settings** page from the sidebar. In the **Workspace** section, choose **Backup**. In a short while, you will be prompted to save a ZIP archive.  
This package includes all notes, images, settings and themes you have.

<br/>

## Restore backup

> Warning: restoring from a backup will replace any existing notes and settings. **It is not possible to merge 2 backups or any existing data.**

<br/>

To restore your data, go to the **Settings** page from the sidebar. In the **Workspace** section, choose **Restore**. You will see a dialog in which you can choose a backup archive. After choosing your package, click **Restore**. If you wish to go back, click **Cancel**. When your data is restored, you will see a message stating that Darkwrite needs to relaunch. Dismiss the notification and Darkwrite will restart for you, with all your previous configurations.  

If the restoration fails, we will put your existing data back in place.  

<br/>

> When you initiate a restore operation, your old data folder is renamed and not deleted. If something goes wrong, we will rename it back so you can continue safely. *You can still access your old data in a folder named `darkwrite-data-old`, which you can find in the user data directory.
